# bram-tasks-design

Design mocks for the Save as task step of [judell/bram#483](https://github.com/judell/bram/issues/483).

Published at https://judell.github.io/bram-tasks-design/. Four tabs, one per project that reported into the issue; each tab shows that repo's real Tasks report with a mocked saved state.

Built by Jon's Claude from the Bram repo; comments go on the issue, not here.
